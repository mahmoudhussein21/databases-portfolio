# Module 1: Introduction to Databases

## My learning goals

In this module, I will practise:

- Understanding what a database is and how it stores information.
- Writing SQL queries to retrieve and summarise data.
- Exploring SQLite, a database that can run locally without a separate database server.
- Using Python to work with database data.
- Checking results carefully and explaining how I verified them.

## My plan

I will work through the SQL Island tutorial, practise SQL with SQLite, and build a small database project. 
I will record my results, errors, and what I learn as I go.
